# SBA - Task Management App


## Overview
This project is a simple Task Management App built with HTML, CSS, and JavaScript. It allows users to create, view, and filter tasks based on their category and completion status. The app also includes a feature to mark overdue tasks and update task statuses directly from the list. The main goal of this project was to practice DOM manipulation, working with arrays, and saving data using localStorage.

---

## Learning Objectives
* Practice creating, reading, updating, and deleting data in JavaScript (CRUD operations).

* Learn how to dynamically update the DOM using JavaScript.

* Understand how to store and retrieve data from localStorage.

* Work with dates and conditional logic to show overdue tasks.

* Improve debugging and problem-solving skills when building interactive web apps.


---

## Description
The Task Management App lets users add new tasks by entering a task name, category, and deadline. Each task starts as “In Progress” and can be changed to “Completed” using a dropdown menu. The app highlights overdue tasks in red and includes filters to display tasks by category or status. All tasks are saved in localStorage, so they remain after refreshing the page. This project focuses on hands-on JavaScript practice and helps reinforce how data, user input, and the browser interface all work together.

## REFLECTION
During this project, I faced several challenges, especially when working with dates, filtering tasks, and switching between Bootstrap and regular CSS. I originally started with Bootstrap but found it was making things more complicated, so I switched to plain CSS to focus more on the JavaScript logic. Understanding how to create and manage elements in the DOM was another challenge — I sometimes added the same elements twice before realizing you only need to create them once, either in HTML or with JavaScript. If I had more time, I would focus on improving my JavaScript skills and better planning the structure of the project before starting. Deciding early whether to build the layout in HTML or generate it dynamically with JavaScript would have made the process smoother and less confusing. Overall, this project helped me understand DOM manipulation more clearly, and I feel more confident about how JavaScript interacts with the page.
